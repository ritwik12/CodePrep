🐍 Python Standard Libraries for DSA

Python's standard library is incredibly powerful. Knowing these collections and utilities is crucial for writing clean code under pressure.

1. Priority Queue: heapq

import heapq
# Min-Heap
heap = []
heapq.heappush(heap, 4)
heapq.heappush(heap, 1)
min_val = heapq.heappop(heap) # 1

# Max-Heap (negate values)
max_heap = []
heapq.heappush(max_heap, -4)
max_val = -heapq.heappop(max_heap) # 4

# Heapify in-place: O(N)
nums = [3, 2, 1]
heapq.heapify(nums)

2. Double-Ended Queue: collections.deque

from collections import deque
# O(1) appends and pops from both ends
queue = deque([1, 2, 3])
queue.append(4)
queue.appendleft(0)
val = queue.popleft() # 0
val = queue.pop() # 4

3. Default Dict: collections.defaultdict

from collections import defaultdict
# Avoid KeyError, initialize missing keys automatically
adj = defaultdict(list)
adj['A'].append('B') # Automatically creates list

count = defaultdict(int)
count['apple'] += 1 # Starts at 0

4. Counter: collections.Counter

from collections import Counter
# Hash map for counting elements
freq = Counter("abacaba") # {'a': 4, 'b': 2, 'c': 1}
top_two = freq.most_common(2) # [('a', 4), ('b', 2)]

5. Binary Search: bisect

import bisect
# Binary search on sorted lists
arr = [1, 3, 3, 6, 7]
# Find insertion point for 3 (right index)
idx = bisect.bisect_right(arr, 3) # 3 (index after the 3s)
idx = bisect.bisect_left(arr, 3) # 1 (first index of 3)

6. Memoization: functools.lru_cache

from functools import lru_cache
# Auto-cache recursive function calls
@lru_cache(maxsize=None)
def fib(n):
    if n < 2: return n
    return fib(n-1) + fib(n-2)

🔄 The 6-Step Interview Workflow

Follow this exact chronological structure during the technical interview. Do not jump into coding immediately!

1

Clarify Requirements & Edge Cases

Ask clarifying questions: "Is the graph connected?", "Are negative values possible?", "Can the inputs contain duplicates?"

2

Explore Constraints & Scale

Check the maximum constraints: "If N is 10^5, an O(N^2) solution will TLE. We need O(N) or O(N log N)."

3

Formulate Brute Force

Explain a brute force approach. Mention its complexity. This guarantees you have a baseline solution.

4

Optimize Design

Pivot to optimal structures (e.g. hash maps, heaps, two pointers). Walk through your algorithm logic verbally before coding.

5

Write Clean Code

Write modular code. Use descriptive variable names. Explain your implementation as you type it.

6

Dry Run & Analyze Complexity

Manually trace your code with a small test case. Finally, state the exact Big-O Time and Space complexities.

💡 Core DSA Interview Patterns

Arrays & Hashing

Used for fast lookups (O(1)). Use frequency Counters or prefix sums. Keep track of indices or complements.

Two Pointers

Use on sorted arrays to scan from ends inwards (like 2Sum) or fast/slow pointers (detecting cycles).

Sliding Window

Contiguous sub-array search. Expand the right pointer, shrink the left pointer once constraints are violated.

Stack

Ideal for nested structures, string parses, or monotonic search patterns (e.g. next greater element).

Trees

Master DFS (Pre, In, Post order) and BFS (level-order). Know Binary Search Tree (BST) operations.

Graphs

Represent via adjacency lists. Cycle detection (BFS Kahn / DFS coloring). Shortest path (BFS / Dijkstra).

🕸️ Advanced Dependency & Parsing Patterns

1. Graph Dependency Modeling

Problems like Course Schedule, Alien Dictionary, and Parallel Courses represent dependencies as directed edges. Build the adjacency list and in-degrees, then apply topological sort.

  • Kahn's Algorithm: Queue processes nodes with 0 incoming dependencies.
  • DFS Topological Sort: Post-order traversal reversed.

2. Spreadsheet/Excel Propagation

Excel cells require recalculation when dependencies change. This can be eager (write-time propagation via DFS) or lazy (read-time recursion with memoization).

  • Track cell dependencies (e.g. A1 -> C3).
  • Detect and raise errors for circular loops.

3. String Parsing & Calculators

String parser problems (like Basic Calculator and Decode String) use stack structures to handle parentheses and order of operations.

  • Save current context (running_sum, sign) onto a stack when encountering '('.
  • Use Shunting-Yard algorithm for operator precedence (*, /, +, -).

4. Complex Data Structure Design

Combining multiple structures allows O(1) operations. For example, LRU Cache uses a Doubly Linked List for insertion order and a Hash Map for fast node retrieval.
